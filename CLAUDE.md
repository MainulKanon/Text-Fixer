# FixIt – project notes for Claude

Windows-only Python tray app: a floating ✨ button (or a hotkey) fixes the text in any focused text box using an AI API. There's also a Reply assistant that drafts a reply to a selected or pasted message.

## Run / build
- Use the venv: `.venv\Scripts\python main.py` (or `pythonw` for no console).
- Install deps: `.venv\Scripts\python -m pip install -r requirements.txt`. Use **PySide6-Essentials**, not full `PySide6`, because full PySide6 pulls a 130 MB WebEngine we don't use.
- Build the exe: `powershell -ExecutionPolicy Bypass -File build.ps1` → `dist\FixIt.exe` (~45 MB, ~1 min). The icon is generated by `python -m ui.icons assets\icon.ico`.
- Install: `powershell -ExecutionPolicy Bypass -File install.ps1` closes a running FixIt.exe, copies it to `%LOCALAPPDATA%\Programs\FixIt\`, creates Desktop and Start-menu shortcuts, repoints the Run key if set, and launches it. After code changes, rerun build + install. The user launches FixIt from the desktop icon.
- The machine runs Python 3.15. `comtypes` prints a FutureWarning on import, which is harmless.
- No test suite. Verify with `python -m compileall -q main.py config.py core ui providers` plus a throwaway smoke script (import modules, test `clean_output`, the clipboard round-trip, and window ex-styles).

## Layout
- `main.py` – `FixItApp`: tray menu, hotkey registration (`keyboard.add_hotkey`), wires the button, fixer, watcher and windows. Single-instance mutex.
- `config.py` – defaults, all prompts (`DEFAULT_SYSTEM_PROMPT` is the user's exact wording, so don't change it), `OUTPUT_RULES` appended to every rewrite prompt, `Config` singleton → `%APPDATA%\FixIt\config.json`. `prompt_for_mode("Fix grammar")` uses `system_prompt`; other modes use `modes[name]`.
- `providers/` – `Provider` / `OpenAICompatibleProvider` base, Groq + OpenRouter (OpenAI-compatible), Gemini (key sent in the `x-goog-api-key` header, never in the URL). `run_chain()` tries `provider_order` and skips providers with no key. On `ModelNotFound` (404, or "model … decommissioned/does not exist"), `complete_with_model_fallback()` calls `list_models()`, then `pick_model()` (uses `preferred_models` and skips `excluded_model_words`), retries, and saves the working model. As of Nov 2026, Groq has **no Llama chat models**. The available ones are `openai/gpt-oss-120b` (default), `gpt-oss-20b` and `qwen/qwen3.8-27b`. gpt-oss/qwen3 get `reasoning_effort: low` for speed. Gemini: `gemini-2.5-flash` is retired. Big flash models (`gemini-flash-latest`, 3.7/3.8-flash) take 17–30 s or more because of thinking, so the default is `gemini-3.5-flash` with `thinkingLevel: minimal` (~2 s). `GeminiProvider` tries minimal → low → none, remembers per model what works, and has a 25 s timeout with a clear "pick a faster model" error. `clean_output()` strips quotes, code fences and "Here is…" lines.
- `core/replacer.py` – `Fixer` (QObject; `_run()` runs one job at a time in a worker thread). `fix()`: Ctrl+A, Ctrl+C (clipboard restored right away) → AI → `preview_ready` if `preview_before_replace` (default **on**), else it replaces right away. `apply(info)` (the preview's Replace) re-copies the field and **refuses if the text changed** since the preview, then Ctrl+A, Ctrl+V. `regenerate(info, mode)` handles Try again (adds `ALTERNATIVE_HINT`) and Change style, with no key sending.
- `ui/fix_panel.py` – **Paste & fix** (user request): the first tab of the Settings window. It's opened by the tray "✨ Paste & fix…" item and by double-clicking the tray icon (`open_settings("fix")`; "Settings…" opens AI providers). You paste text, pick a style, and Fix (Ctrl+Enter) shows a diff-highlighted result with Copy / Try again / Edit this. Save/Cancel are hidden on this tab. Results go to history. `ALTERNATIVE_HINT` lives in `core/replacer.py` and is shared; it was made stronger because the old wording gave near-identical retries.
- `ui/preview_popup.py` – non-activating preview card (same rules as the button). It shows the original crossed out, the new text with changed words highlighted green (`diff_html`), and Replace / Try again / Copy / Change style ▾ / ✕. It closes itself when the user switches to another app. `grab_selection()` (Ctrl+C only) feeds the Reply window. `paste_into(hwnd, text)` handles Reply → Insert.
- `core/focus_watcher.py` – polling thread (0.2 s) using `uiautomation` inside `UIAutomationInitializerInThread`. It decides show/hide and emits field, caret and mouse rects in **physical pixels**. Typing activity comes from `keyboard.hook`, which ignores keys FixIt injects (`keys.injecting`) and keys pressed while the fixer is busy.
- `core/keys.py` – `send`, `wait_modifiers_released` (the hotkey's Ctrl/Shift are still held when it fires), `focus_window` (AttachThreadInput + Alt tap to get past SetForegroundWindow limits).
- `core/clipboard.py` (win32clipboard; only safe formats are snapshotted), `history.py` (last 20 → `%APPDATA%\FixIt\history.json`), `startup.py` (HKCU Run key).
- `ui/` – `floating_button.py` (user-chosen **style B**: soft lavender pill "✨ Fix grammar". States are ready / hover / busy "Fixing…" spinner / done green "Fixed · Ctrl+Z to undo", which then hides. Its width follows the label. Placement is `compute_position()`: **above the field's top-right corner**, so it never covers send/mic buttons inside the field (user request). If there's no room above, it goes below. Tall editors with a caret: right of the caret, or just above the caret line. The preview card opens below the field), `toast.py`, `settings.py`, `reply_window.py`, `history_window.py`, `icons.py` (icon drawn with QPainter, no image files), `winstyle.py` (win32 helpers).

## Android app (`android/`)
- The user chose the **text-selection menu** approach (`ACTION_PROCESS_TEXT`): "FixIt" (`FixActivity`: preview → Replace returns `EXTRA_PROCESS_TEXT`) and "FixIt Reply" (`ReplyActivity`: draft → Copy). Battery is the top requirement: **no services, receivers, WorkManager or polling.** Work runs on one short-lived thread per request (`Bg`).
- Plain Java with **zero dependencies** (platform APIs only: HttpURLConnection, org.json, Keystore AES-GCM for API keys in `Prefs`). The APK is ~52 KB. `Ai.java` ports the desktop provider chain (Groq → Gemini → OpenRouter, model auto-replacement, Gemini thinkingLevel minimal → low → none, `clean()`), and `Prompts.java` mirrors config.py.
- Build: `powershell -ExecutionPolicy Bypass -File android\build.ps1` (offline; Android Studio's JBR + cached Gradle 9.5.1 + AGP 9.3.2, compileSdk/targetSdk 37, minSdk 24) → `dist\FixIt-android.apk`, signed with the debug key for sideloading. `local.properties` must use forward slashes. A style named `FixIt.X` needs the empty base style `FixIt`.
- **Tested on the user's phone** (Redmi Note 10S, Android 13, MIUI 14), connected over Wi-Fi adb (`adb devices` shows `adb-…_adb-tls-connect._tcp`). FixActivity (real Groq fix with green diff) and ReplyActivity both work, and the crash log is clean. Test without touching the phone: `adb shell am start -a android.intent.action.PROCESS_TEXT -t text/plain -n com.fixit.app/.FixActivity --es android.intent.extra.PROCESS_TEXT '...'`, then `adb exec-out screencap -p` via `cmd /c` redirect (PowerShell `>` corrupts the PNG).
- Android gotchas: `Pattern.UNICODE_CHARACTER_CLASS` **crashes on Android**, so use `\p{L}\p{M}\p{N}` classes. Password EditTexts default to monospace (set `Typeface.DEFAULT`). MIUI: `adb install` can fail with INSTALL_FAILED_USER_RESTRICTED or hang on the "Install via USB" prompt. The fallback is `adb push` to `/sdcard/Download` and the user installs it from File Manager. `input keyevent` is blocked (no INJECT_EVENTS), and a black screenshot means the screen is asleep (`dumpsys power` → Dozing).
- The user enters API keys on the phone themselves (never type keys into the app for them).
- Confirmed by the user: the selection-menu entry plus **Replace work in WhatsApp**. Fiverr and Gmail are not reported yet.

## Marketing (`marketing/`)
- `render_post_images.py` → `linkedin/*.png` (1080² LinkedIn images; API keys masked). `linkedin/post.md` holds the post text (EN + BN).
- Video: `video/script.md` (scripts + YouTube titles), `video/voiceover.json` (8 lines per language, also used for captions).
  - `gen_voice.py <lang> [--voice id]` calls the ElevenLabs API; the key comes from env `XI_KEY` and is never saved. Only **eleven_v3** supports Bangla. The user's key is TTS-only (no voices/models read) and the account is **free**, so library voices like Tanvir (`SamfdZr6Xh6ZtPUGZUhg`) are refused through the API. The user generates those on the website instead.
  - `split_voice.py <lang>` cuts one long `audio/<lang>/full.mp3` into `1..8.mp3`. It uses DP matching of pauses to text-length boundaries; the largest-pauses-only approach mis-split.
  - `make_video.py <lang> [--square] [--preview]` renders frames from the real widgets (QT_SCALE_FACTOR=3) and pipes them to ffmpeg (`imageio-ffmpeg`, venv only; ffmpeg 9 uses `-fps_mode`, not `-vsync`). Scene length = voice clip + 0.8 s. Output goes to `video/out/`. Exit code 9 after "saved" is Qt teardown and harmless.
  - Voices: English = George (`JBFqnCBsd6RMkjVDRZzb`, via API); Bangla = Tanvir (user-generated).

## Invariants – don't break these
- The ✨ button and the toast must **never take focus**: WS_EX_NOACTIVATE | TOOLWINDOW | TOPMOST, `WA_ShowWithoutActivating`, and `nativeEvent` returning `MA_NOACTIVATE` for WM_MOUSEACTIVATE. Position them with `winstyle.move_physical` (SetWindowPos in physical px), not Qt `move()`, because UIA coordinates are physical.
- Never show the button in password fields (`IsPassword`) or in apps on `excluded_apps`.
- If the API fails, leave the user's text untouched and show a red toast. Always restore the clipboard in `finally`.
- Never hardcode API keys. They live only in config.json.
- Worker threads talk to the UI only through Qt signals.
- To add a provider: subclass it in `providers/`, add it to `PROVIDERS` in `providers/__init__.py`, and add a default model to `PROVIDER_DEFAULTS` in `config.py`. Settings picks it up automatically.
