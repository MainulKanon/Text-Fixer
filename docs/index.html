Questionsপ্রশ্ন ও উত্তর

Is it really free?সত্যিই কি ফ্রি?

Yes. The apps are free (source code on GitHub), and the AI services have free tiers that are plenty for daily client messages.হ্যাঁ। অ্যাপ দুটো ফ্রি (সোর্স কোড GitHub এ), আর AI সার্ভিসগুলোর ফ্রি লিমিট প্রতিদিনের ক্লায়েন্ট মেসেজের জন্য যথেষ্ট।

Why does Windows say "Windows protected your PC"?Windows কেন "Windows protected your PC" দেখায়?

Windows shows this for new apps that aren't from a big publisher. Click More info, then Run anyway. The full source code is on GitHub.বড় কোম্পানির না হলে নতুন অ্যাপে Windows এটা দেখায়। More info চেপে Run anyway দিন। পুরো সোর্স কোড GitHub এ আছে।

Is my text or key sent anywhere?আমার লেখা বা key কি কোথাও যায়?

Your key stays on your device. The text you choose to fix is sent only to the AI service you set up (for example Groq) to get the result. Nothing is sent to us.key আপনার ডিভাইসেই থাকে। যে লেখা ঠিক করতে চান, শুধু সেটা আপনার বেছে নেওয়া AI সার্ভিসে (যেমন Groq) যায়। আমাদের কাছে কিছুই আসে না।

Does it drain my phone battery?ফোনের ব্যাটারি কি খরচ হয়?

No. On Android it only starts when you tap it in the text menu and closes when you're done. No background service, no notifications.না। Android এ শুধু মেনু থেকে চাপলে চালু হয়, কাজ শেষে বন্ধ হয়ে যায়। কোনো ব্যাকগ্রাউন্ড সার্ভিস বা নোটিফিকেশন নেই।
